# Cabi brand assets

Place the supplied brand files here using these names:

- `cabi-main.png` — the main anime Cabi character wearing the purple CPU shirt.
- `cabi-mascot.png` — the purple mini Cabi mascot.
- `cpu-reference.png` — design reference only; the application does not render it.

The interface reserves stable dimensions and shows a neutral CABI monogram when an asset is missing. It never substitutes a different character.
